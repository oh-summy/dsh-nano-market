# @oh-summy/nano-market

Nano Market —— DSH 插件市场的管理页。它在 **插件 → Nano Market** 页签下列出本市场注册的全部插件。

**生命周期模型（0.2.0 起）**：安装 Nano Market = 本市场全部插件随即就位——每个插件只有两种操作：
**打开（启用开关）** 与 **更新**（市场有新版本时行内按钮，走宿主更新对话框）。不提供单独的安装/卸载入口。

## Quick Start

1. **安装**：在 DSH 的「插件 → 发现」里安装 `@oh-summy/nano-market`。
2. **使用**：打开「插件 → Nano Market」，本市场所有插件直接可用：
   - 每行右侧是启用开关（打开 = 启用，关闭 = 不生效）；
   - 市场有新版本时，行内出现「可更新」徽章与「更新」按钮（开关左侧）；
   - 点插件名进入该插件在 DSH 里的详情页（配置表单由宿主渲染）。

## 说明

- 更新走宿主的更新对话框（停止并移除已装版本 → 安装目标版本 → 失败自动装回）。
- 市场索引来自本市场自己的 `index.json`，条目与安装 spec 由宿主解析，插件不自己拼 spec。
- 本插件没有服务端逻辑，也没有需要用户填写的配置项。
