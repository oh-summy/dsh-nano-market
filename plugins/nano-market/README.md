# @oh-summy/nano-market

Nano Market —— DSH 插件市场的管理页。它在 **插件 → Nano Market** 页签下列出本市场注册的全部插件，
并提供安装、启用、停用、卸载；点「配置」会进入该插件在 DSH 里的详情页（配置表单由宿主渲染）。

## Quick Start

1. **安装**：在 DSH 的「插件 → 发现」里安装 `@oh-summy/nano-market`。
2. **使用**：打开「插件 → Nano Market」，即可看到本市场所有插件。
   - 未安装的插件：「安装」按钮（走宿主的确认与安装流程）。
   - 已安装的插件：「配置」「停用」「卸载」。
3. **配置**：点「配置」进入插件详情页，在那里填写配置（各插件自己的配置表单）。

## 说明

- 本插件只负责「列出 + 装卸」，不代理任何插件的配置；配置一律在插件自己的详情页完成。
- 市场索引来自本市场自己的 `index.json`，条目与安装 spec 由宿主解析，插件不自己拼 spec。
- 本插件没有服务端逻辑，也没有需要用户填写的配置项。
